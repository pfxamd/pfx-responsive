# PFx Responsive source version

PFx Release Core v0.1.0-alpha.4 tracks source changes and synchronizes version.json, the badge, and package metadata. The **application source version** is separate from the previously published, pinned Windows portable release (`v0.2.0-alpha.2`) and from the independently versioned Preview Core. Existing Windows archive publishing is unchanged; this version metadata is not a claim that new Windows binaries have been shipped.
